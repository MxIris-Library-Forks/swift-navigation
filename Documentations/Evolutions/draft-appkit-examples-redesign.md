# Draft - AppKit 案例改用系统设置式的分组排版

- **状态**: In Progress
- **创建日期**: 2026-11-14
- **最后更新**: 2026-11-14
- **实现分支**: `appkit-examples-redesign`

## 摘要

AppKit 案例里有一半页面是照着 UIKit 案例逐行移植的：几个按钮堆在窗口正中，状态用 ✅/❌ 写进按钮标题；较新的页面从左上角往下排，每节一个粗体标题，能用但简陋。Basics 页里由布尔值弹出的 sheet 只有一行「Hello!」，没有任何按钮，弹出来就关不掉；Wi-Fi 案例的网络详情 sheet 也一样，在「忘记网络」的确认框里取消之后就没有出口。这一批把全部 AppKit 案例（15 个案例页，加上 Wi-Fi 案例的 3 个页面）改成「系统设置」那样的分组排版，并让每个弹出的 sheet 都能关掉。

## 方案

- **共享排版**放进已有的 `AppKit+CaseStudySupport.swift`，不新建源文件，也就不用改 `Examples.xcodeproj`：
  - 页面：一列分组，放在可以滚动的区域里，靠上、水平居中，有最大宽度。
  - 分组：上方一行粗体标题，中间一个圆角框装着若干行，行与行之间画分隔线，下方可以有一段说明。
  - 行：左边是名称，右边是状态文字和控件；表格、画布、日志这类内容占满整行。
- **每页只换排版**，演示的 API 和行为不变。状态改成行里的文字，不再写进按钮标题。
- **sheet 都能关掉**：弹出的内容都有 Done 按钮，回车可以触发；按 Esc 也能关，做法见决策日志。

落地步骤（每步各自编译通过）：

1. 共享排版；Basics 与 Wi-Fi 网络详情的 sheet 加上关闭的办法。（已完成）
2. 其余页面逐页换成分组排版。（已完成）
3. 编译 CaseStudies 的 macOS 版，启动 App 逐页截图检查，修排版问题。（已完成）

没有询问就采用的假设：

- 分组标题照「系统设置」用粗体，不用选样式时预览里的全大写。
- 共享排版只用 AppKit，不用 AppKitPlus：多数案例只依赖 AppKitNavigation，读者在页面代码里看到的应当只有这个库的用法。
- 工具栏上的「About」按钮和各案例的说明文字保持原样。
- NSControl bindings 页原先把模型里的颜色涂满整页背景，改为只由颜色井显示：整页背景会盖掉分组框的层次。默认颜色从窗口背景色改成系统蓝，否则颜色井看起来是空的。
- Focus 页原先把有焦点的文本框涂成浅灰，深色模式下很刺眼，改成把那一行的名称染成强调色。
- Basics 页的 sheet 内容从 SwiftUI 改用案例共用的 AppKit 视图控制器，与其他页面的 sheet 一致；它的 Done 按钮清空状态，演示由状态关闭。Basics 模型里装打开面板提示语的属性从 `alert` 改名为 `openPanelMessage`，那里弹的早就不是 alert。
- Animations 页的圆默认改用系统蓝，颜色循环最后也回到系统蓝：原来的黑色在深色模式下几乎看不见。
- Wi-Fi 设置页本来就是分组列表，只把分组框、宽度和边距对齐到其他页面；连接网络的面板给 Join 配上回车、给 Cancel 配上 Esc。

## 决策日志

| 日期 | 决定 | 理由 |
|------|------|------|
| 2026-11-14 | Created as Draft | Basics 页由布尔值弹出的 sheet 关不掉，AppKit 案例的界面也太简陋 |
| 2026-11-14 | 用户批准，开始实现 | 用户选定改全部 AppKit 页面、用系统设置式分组，并同意做完后由 agent 启动 App 逐页截图检查 |
| 2026-11-14 | sheet 关不掉不是去掉 AppKitNavigationShim 引入的 | 这个 sheet 的内容从 2024 年起就只有一行文字，它所在的文件也没被那次改动碰过；`main` 上同样关不掉 |
| 2026-11-14 | 分组、行和整页改用约束排列，不用 `NSStackView` 的 `.width` 对齐 | 第一次截图时整列都靠右、行内名称被挤到右边：`NSStackView` 的 `.width` 对齐并不会把子视图撑满宽度。改成自己用约束一个接一个地排，隐藏的行不占位置，分隔线跟着重画 |
| 2026-11-14 | Esc 关 sheet 由被弹出的视图控制器实现 `cancel(_:)` | 逆向 macOS 27.2 的 AppKit 得知：视图控制器弹出的 sheet 按 Esc 默认只会响一声；弹出时被呈现的视图控制器成为 sheet 窗口的 delegate，窗口处理 Esc 时先问 delegate 有没有 `cancel:`。这条路走的仍是正常的关闭流程。截图检查时示例 App 不在前台，后台发送的 Esc 送不到，还没在运行中验证 |
| 2026-11-14 | 实现完成，待用户看过后收尾 | `CaseStudies` 的 macOS 版编译通过，改动的文件没有警告。启动 App 逐页截图检查了 15 个案例页和 Wi-Fi 设置页，并点开 Basics 与 Dismissal 的 sheet、用 Done 关掉；Wi-Fi 网络详情的 sheet 要靠鼠标悬停才出现的按钮打开，没截到。文档判断：案例本身就是示例文档，不需要另写使用指南或实现说明，没有新术语 |
